# Christian Mesía-Montenegro — academic website

Static, dependency-free academic website. The homepage is fully self-contained (CSS and JavaScript are embedded in `index.html`) so it can be opened locally or published directly with GitHub Pages.

## Publish with GitHub Pages
1. Create a GitHub repository, e.g. `christianmesia.github.io` or `academic`.
2. Upload the contents of this folder to the repository root.
3. In GitHub: **Settings → Pages → Deploy from a branch → main / root**.
4. The site will be available at your GitHub Pages address.

## Main files
- `index.html` — complete website
- `data/publications.bib` — publications and selected book chapters in BibTeX

No build system, theme installation, Node, Hugo, or external CSS is required.

Executive CV documents have been intentionally removed from the public version pending a disclosure review. Do not upload internal institutional budgets, staffing data, contractual terms, or unpublished performance metrics.
